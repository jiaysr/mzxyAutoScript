使用说明

基本流程

  1. 选择或拖入一张/多张截图，左侧列表切换图片。
  2. 在画布上拖动红框移动裁剪区域，拖红框四角缩放；默认红框与标注器一致为 100×100，点「全图」可恢复整张图片。
  3. 选择保存文件夹（推荐 Chrome / Edge），确认文件名后点「保存当前」或「保存全部」。

保存说明

选择文件夹使用浏览器 File System Access API：保存时直接写入所选目录，不经过服务端。首次使用需要授权；浏览器允许时会记住上次的文件夹。

出于安全限制，浏览器只暴露所选文件夹的名称（如 res），不会显示完整磁盘路径；保存结果以文件名预览为准。

Firefox / Safari 等不支持该能力时，保存按钮会改为下载文件；多张会连续下载，浏览器可能提示「允许多个下载」。

项目约定

截图基准为 1280×720；素材命名常用 res_<itemName>.png，可直接点「res_ 前缀」模板。裁剪导出固定为 PNG，坐标按原图像素取整并限制在图片范围内。

所有图片处理都在本机浏览器内完成，不会上传到任何服务器，也不需要启动 OAS 服务。
